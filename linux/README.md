# Соучастник для Arch Linux / CachyOS

Минимальная desktop/CLI-версия без Android IME и экранной клавиатуры. Оставлены две функции:

1. проверка текста по локальному словарю триггеров и вывод возможных статей-кандидатов;
2. поиск упоминаний из локального реестра и вывод требуемых/справочных меток (иноагенты, сервисы и т. п.).

Программа не отправляет текст в сеть. Это не юридическая консультация. Триггер не доказывает наличие состава: он только поднимает кандидата для проверки.

## Запуск

```bash
cd linux
python souchastnik.py 'текст для проверки'
printf '%s\n' 'текст для проверки' | python souchastnik.py
python souchastnik.py --json 'текст для проверки'
```

## Arch/CachyOS

Для запуска из исходников достаточно `python`. Для системной установки можно собрать пакет из каталога `linux` после клонирования репозитория:

```bash
sudo pacman -S --needed base-devel python
cd linux
makepkg -si
souchastnik 'текст для проверки'
```

## Данные

`data/articles.json` — справочник статей. `data/triggers.json` — локальные триггеры, которые только формируют список кандидатов. `data/agents.json` — шаблоны и реестр меток.

В Android-версии исходный `triggers.json` намеренно не опубликован, поэтому здесь лежит только безопасный пример структуры. Аналогично список иноагентов следует заполнить актуальными данными и сверять с официальным реестром перед использованием. Не полагайтесь на старую копию реестра.

## Что удалено из Linux-версии

Нет `InputMethodService`, Android `Manifest`, AIDL, экранной клавиатуры, Android UI, разрешений и фонового сервиса. Linux-версия не перехватывает ввод: ей явно передают текст через аргумент или stdin.

## Дальнейшее развитие

Если нужен полный локальный AI-судья, следующим шагом можно подключить системный `llama.cpp` из Arch/AUR и перенести закрытый выбор из `llama_bridge.cpp`. Текущая версия намеренно не выдаёт словарный матч за решение модели.
